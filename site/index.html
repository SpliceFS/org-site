SpliceFS GitHub

One folder, streamed from several servers at once

SpliceFS mounts a read-only folder whose files are streamed from several servers at once. Every server that holds a copy of a file serves blocks of it, and the client splices the blocks back together in order, caching them on local disk.

It is built for throughput: a reader far away from every server gets the combined upload speed of all of them, and a slow or failing server is routed around while a file is being read.

Status: alpha, step one. Read-only is the first step toward a complete distributed filesystem. Nothing has been released and it has not run in production. See how it compares with mature systems today.
