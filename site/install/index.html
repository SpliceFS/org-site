Install SpliceFS

Linux and FreeBSD, on x86-64 and arm64.

Debian

Debian 12 and 13.

Step 1: Set up the repository

Installs no package. As root, leave out sudo.

A new Debian has neither curl nor wget. Install curl first:

Debian: install curl
sudo apt-get update && sudo apt-get install -y curl
Debian
curl --proto '=https' --tlsv1.2 -fsSL https://packages.splicefs.org/setup.sh -o ~/splicefs-setup.sh &&
  sudo sh ~/splicefs-setup.sh
Verify the signatures
Get the signed script and the key
curl -fsSLo ~/splicefs-setup.sh.asc https://packages.splicefs.org/setup.sh.asc
curl -fsSLo ~/splicefs.asc https://packages.splicefs.org/keys/splicefs.asc
gpg --show-keys --fingerprint ~/splicefs.asc
gpg --import ~/splicefs.asc

The fingerprint must match the one on GitHub.

Verify, then write out the script
gpg --verify ~/splicefs-setup.sh.asc &&
  gpg --output ~/splicefs-setup.sh --decrypt ~/splicefs-setup.sh.asc

Step 2: Install

Debian
sudo apt-get update
sudo apt-get install splicefs-server    # the server
sudo apt-get install splicefs-client    # the client

Step 3: Start the service

Installing does not start the service.

Debian
sudo systemctl enable --now splicefsd    # the server
sudo systemctl enable --now splicefs     # the client

Next: server configuration, client configuration.

Other tasks

Mount at boot
Debian, as root
echo 'example:/ /mnt/files splicefs _netdev,nofail,x-systemd.requires=splicefs.service 0 0' >> /etc/fstab

The client's cluster must be defined and its service running.

Run as yourself
Terminal 1: your folders, your cluster, the client
# Your own folders, in your home directory: your cluster and its password.
config="${XDG_CONFIG_HOME:-$HOME/.config}/splicefs/client"
mkdir -p "$config/clusters.d" "$config/secrets" ~/files

# Your cluster. The file name is the cluster name.
cat > "$config/clusters.d/example.yaml" <<'EOF'
url: "https://east.example.com/api"
user: alice
password_file: secrets/example
EOF
(umask 077; cat > "$config/secrets/example")   # type the password, then Ctrl-D

# Start the client as yourself. It stays in the foreground: give it a terminal of its own.
splicefs
Terminal 2: mount, read, unmount
# In a second terminal: mount the cluster in your folder, see it, read it, unmount it.
splicefsctl mount example:/ ~/files
splicefsctl status
ls ~/files
cat ~/files/media/hello.txt   # a file of your cluster
splicefsctl umount ~/files

Leave the service off. Needs client 0.5.36 or newer. Without /dev/fuse: modprobe fuse as root.

Upgrade

An upgrade of the package restarts its running service by itself.

Remove the repository
Debian
curl --proto '=https' --tlsv1.2 -fsSL https://packages.splicefs.org/setup.sh -o ~/splicefs-setup.sh &&
  sudo sh ~/splicefs-setup.sh --remove

Removes no package. A file you changed stays, with a warning.

Uninstall completely
Debian
# Remove the packages and their configuration files. Leave out the one you did not install:
sudo apt-get purge splicefs-server splicefs-client

# Remove the packages they needed that nothing else needs now:
sudo apt-get autoremove --purge

# Delete the data and the configuration folder, then the user and its group:
sudo rm -rf /var/lib/splicefs /etc/splicefs
sudo userdel splicefs

# Remove the repository and the signing key, with the setup script from step 1:
sudo sh ~/splicefs-setup.sh --remove

Also deletes the data, the configuration and the user. Check the package list before you confirm.

Set up the repository by hand
Debian
# Add the SpliceFS signing key:
sudo apt-get update
sudo apt-get install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl --proto '=https' --tlsv1.2 -fsSL https://packages.splicefs.org/keys/splicefs.asc -o /etc/apt/keyrings/splicefs.asc
sudo chmod a+r /etc/apt/keyrings/splicefs.asc

# Add the repository to apt sources:
sudo tee /etc/apt/sources.list.d/splicefs.sources >/dev/null <<'EOF'
Types: deb
URIs: https://packages.splicefs.org/server/apt https://packages.splicefs.org/client/apt
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/splicefs.asc
EOF

# Update the package index, then install the server, the client, or both:
sudo apt-get update
sudo apt-get install splicefs-server    # the server
sudo apt-get install splicefs-client    # the client

Red Hat Enterprise Linux
# Add the SpliceFS signing key:

[splicefs-server]
name=SpliceFS server
baseurl=https://packages.splicefs.org/server/rpm/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs

[splicefs-client]
name=SpliceFS client
baseurl=https://packages.splicefs.org/client/rpm/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-splicefs
